# Práctica de Integración Continua con GitHub Actions y ntfy.sh

Repositorio configurado para automatizar una alerta mediante **GitHub Actions** cada vez que se sube código nuevo a la rama principal (`main`).

## 🚀 Contenido del Proyecto
- **`main.py`**: Programa básico en Python con el mensaje "¡Hola Mundo!".
- **`.github/workflows/alerta.yml`**: Script de GitHub Actions que detecta el *push* en la rama `main` y envía una notificación automática a [ntfy.sh/devops-itla](https://ntfy.sh/devops-itla).
